# 🗺️ APSNY-TRANSFER — План реализации

> Агрегатор трансферов и поездок (РФ ↔ Республика Абхазия)
> Стек: React 19 + Vite + TypeScript + Tailwind CSS v4 + Framer Motion + Supabase

---

## 📊 Текущее состояние проекта

### ✅ Уже реализовано
- Базовая структура проекта (Vite + React + TS + Tailwind v4)
- Дизайн-система: тёмная тема, glassmorphism, кибер-акценты (#00f0ff / #7701d0)
- Шрифты: Hanken Grotesk + Sora + JetBrains Mono
- Страница `Auth.tsx` — лендинг + форма входа/регистрации (пассажир/водитель)
- Страница `Feed.tsx` — лента поездок с real-time обновлениями через Supabase Realtime
- Страница `CreateTrip.tsx` — 3-шаговая форма создания поездки
- Страница `Profile.tsx` — базовый профиль + управление автомобилями (для водителей)
- Страница `Messages.tsx` — список чатов (привязанных к поездкам)
- Страница `Chat.tsx` — чат по поездке
- Layout: `MainLayout` (Sidebar на desktop + BottomNav на mobile)
- Базовая схема БД Supabase: users, vehicles, rides, bids, messages + RLS политики + RPC `place_bid`

### ❌ Проблемы текущей реализации
- Роль водителя называется `operator` (непоследовательно, надо `driver`)
- В таблице `rides` нет поля `auction_end_time` — аукцион не имеет временного лимита
- В таблице `rides` нет поля `winner_id` — непонятно, кто выиграл
- В таблице `users` нет полей: `telegram`, `whatsapp`, `avatar_url`
- Нет настроек приватности (какие данные показывать)
- Нет таблицы `reviews` для рейтингов
- Нет таблицы для прямых сообщений (user-to-user, не привязанных к поездке)
- Нет страницы деталей поездки (`/trips/:id`)
- Нет страницы рейтингов
- Нет страницы просмотра профиля другого пользователя
- Форма CreateTrip не передаёт `auction_end_time`
- RPC `place_bid` вызывается с неверным параметром (`p_amount` вместо `p_bid_amount`)
- Незарегистрированные пользователи не могут просматривать ленту (сейчас редирект на логин)

## 🗄️ ЭТАП 0 — Переработка схемы БД Supabase

**Файл:** `supabase_schema_v2.sql`

### Изменения в таблицах:

#### `users` — добавить поля:
```sql
telegram        TEXT,
whatsapp        TEXT,
avatar_url      TEXT,
show_phone      BOOLEAN DEFAULT false,
show_telegram   BOOLEAN DEFAULT true,
show_whatsapp   BOOLEAN DEFAULT true,
rating          NUMERIC(3,1) DEFAULT 0,
trips_count     INTEGER DEFAULT 0
-- role: изменить CHECK на ('passenger', 'driver')
```

#### `vehicles` — добавить:
```sql
photo_url   TEXT  -- одно фото авто (не массив)
```

#### `rides` — добавить/изменить:
```sql
auction_end_time  TIMESTAMP WITH TIME ZONE,  -- когда заканчивается торг
winner_id         UUID REFERENCES users(id), -- победитель аукциона
bid_step          INTEGER DEFAULT 50,         -- минимальный шаг ставки
border_crossing   BOOLEAN DEFAULT false,      -- пересечение границы
status: добавить 'pending_payment'
```

#### Новые таблицы:

**`reviews`** — отзывы и оценки:
```sql
id          UUID PRIMARY KEY
ride_id     UUID REFERENCES rides(id)
reviewer_id UUID REFERENCES users(id)   -- кто оставил
target_id   UUID REFERENCES users(id)   -- о ком отзыв
rating      INTEGER CHECK (1-5)
comment     TEXT
created_at  TIMESTAMP
```

**`conversations`** — прямые диалоги между пользователями:
```sql
id            UUID PRIMARY KEY
user1_id      UUID REFERENCES users(id)
user2_id      UUID REFERENCES users(id)
ride_id       UUID REFERENCES rides(id) NULLABLE -- если начат через поездку
last_message  TEXT
last_message_at TIMESTAMP
created_at    TIMESTAMP
```

**`direct_messages`** — сообщения в диалоге:
```sql
id              UUID PRIMARY KEY
conversation_id UUID REFERENCES conversations(id)
sender_id       UUID REFERENCES users(id)
content         TEXT
is_read         BOOLEAN DEFAULT false
created_at      TIMESTAMP
```

### Новые RPC функции:
- `accept_bid(p_ride_id, p_winner_id)` — принять ставку, закрыть аукцион
- `finish_auction(p_ride_id)` — автоматически завершить аукцион (вызывается cron/edge function)
- `submit_review(p_ride_id, p_target_id, p_rating, p_comment)` — оставить отзыв + обновить рейтинг

**Статус:** ✅ Выполнено (2026-05-12)
