## Дефекты

### 1. Лишний «0» рядом с ценой в «Мои поездки» — функциональный баг

**Где:** `src/pages/MyTrips.tsx:138`
**Что видно:** у поездки без ставок рядом с ценой печатается голый ноль: `4200 ₽ 0`.
**Почему:** классическая ловушка React — `{trip.bids_count && trip.bids_count > 0 && (…)}`.
При `bids_count === 0` выражение возвращает число `0`, и React его рисует.

```diff
- {trip.bids_count && trip.bids_count > 0 && (
+ {!!trip.bids_count && trip.bids_count > 0 && (
```

Проверено: у поездки с одной ставкой бейдж «1 ставка» рисуется правильно — баг только на нуле.
Других мест с таким же паттерном в коде нет.

---

### 2. «Квитанция об оплате» ведёт в тупик — функциональный баг

**Где:** `src/pages/MyTrips.tsx:94` (`isPaid`)
**Что видно:** кнопка «Квитанция об оплате» показывается у всех поездок,
но при бесплатной публикации открывается заглушка «Квитанция не найдена».
**Почему:** `isPaid` вычисляется из статуса поездки, а не из факта оплаты:

```ts
const isPaid = trip.status !== 'draft' && trip.status !== 'cancelled';
```

Пока действует бесплатный период, платежа нет ни у одной новой поездки — значит кнопка
битая у всех. Нужно опираться на реальную запись платежа (или на `amount > 0`).

---

### 3. Уведомление не отмечается прочитанным при клике — функциональный баг

**Где:** `src/pages/Notifications.tsx:188-195`
**Что видно:** открыл уведомление → перешёл на карточку поездки → вернулся:
уведомление всё ещё непрочитанное, счётчик так и держит «19 непрочитанных» и бейдж «9+».
**Почему:** карточка обёрнута просто в `<Link>`, обновления `is_read` для одного элемента нет.
Прочитать можно только кнопкой «Прочитать все».
**Лечится:** в `onClick` ссылки перед переходом обновлять `is_read` у этого уведомления.

### 4. Выпадающие панели даты и времени слишком прозрачные — визуальный баг

**Где:** `src/components/ui/TimePicker.tsx:83`, `src/components/ui/DatePicker.tsx:95`
**Что видно:** сквозь панель читается блок «Удобства в поездке» — цифры часов
перемешиваются с надписями «Ваша музыка», «Место для багажа», «Некурящий».
**Почему:** фон `bg-surface-container/95` + `backdrop-blur-md`. На тёмной теме
пятипроцентной прозрачности хватает, чтобы светлый текст под панелью читался.
**Проверено вживую:** подставил панели сплошной `#1d2026` через DevTools —
просвечивание исчезло полностью, читаемость нормальная.

```diff
- bg-surface-container/95 backdrop-blur-md
+ bg-surface-container-high backdrop-blur-md
```

### 5. Минуты уходят за нижний край экрана — визуальный баг

**Где:** те же `TimePicker.tsx` / `DatePicker.tsx`
**Что видно:** панель времени высотой ~312 px всегда раскрывается вниз. При невысоком
окне (проверено на видимой области 639 px) пользователь видит только «Часы»; блок
«Минуты» и подсказка остаются ниже сгиба. Человек выбирает час, видит в поле `--:--`
и решает, что сломалось.
**Лечится:** либо `scrollIntoView` панели при открытии, либо раскрывать вверх,
когда снизу не хватает места, либо ставить часы и минуты в две колонки рядом.

---

### 6. Склонение «3 мест» вместо «3 места» — текст

**Где:** `src/pages/CreateTrip.tsx:470`, `src/pages/Profile.tsx:1256`
Вместимость автомобиля печатается как `{capacity} мест` без склонения.
В счётчике мест на шаге 2 склонение сделано правильно — стоит вынести общий хелпер.

---

### 7. Суммы в уведомлениях с хвостом «.00» — текст

**Где:** `supabase/migrations/20260604_denormalize_bids.sql:150`,
`supabase/migrations/20260810_fix_1_5_accept_current_price_auth.sql:129`
`'Ставка: ' || v_ride.current_price || ' ₽'` даёт «Ставка: 4500.00 ₽», тогда как
во всём интерфейсе формат «4 500 ₽». Лечится через `to_char(..., 'FM999G999')`.
