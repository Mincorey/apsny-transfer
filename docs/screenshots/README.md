# Скриншоты для README

Положи сюда три PNG-скриншота с такими именами (их ждёт главный README):

| Файл | Что на скриншоте |
| --- | --- |
| `01-landing.png` | Главная страница (лендинг «Динамические трансферы по вашей цене») |
| `02-feed.png` | Лента активных аукционов (карточка поездки) |
| `03-register.png` | Экран регистрации / выбора роли |

Рекомендации: вертикальные мобильные скриншоты, ширина ~900–1200px, формат PNG.
После добавления файлов закоммить их вместе с README — картинки появятся на странице репозитория.
